# Pro 功能原理

下列 15 个本地入口共同使用官方 React Flow。布局和编辑规则位于本包源码，第三方计算通过正常 npm 依赖调用。每个入口的图状态与缓存独立，重挂载恢复初始状态。

| 功能     | 执行逻辑与关键边界                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 节点动画 | 保存当前坐标与目标坐标，D3 timer 按 `from + (to - from) × progress` 插值，结束时写回准确目标；切换目标先停止旧动画。                                            |
| 动态树   | 根据入边确定父节点，用 D3 层级树计算位置；点击占位节点完成转换并追加末端占位，添加子分支或边中插入后重新布局。                                                  |
| 自动布局 | 等待测量尺寸就绪；Dagre 返回的中心坐标减去半宽高，D3 使用虚拟根容纳多根，ELK 异步返回后按 ID 合并。方向同时决定坐标轴和 source/target 方位。                    |
| 力布局   | 将画布节点复制为模拟粒子，叠加排斥、连线与居中力；每个 tick 回写坐标。拖动时用 `fx/fy` 固定目标粒子，结束后释放并加热模拟。                                     |
| 展开折叠 | 保留原始图与 expanded 状态，布局派生图只包含可见后代。折叠移除的是派生布局中的后代，展开后可恢复原数据；参数改变后重算树间距。                                  |
| 图形     | 按实际尺寸生成椭圆、多边形、箭头等 SVG；侧栏拖入时把屏幕坐标转成画布坐标。文字、颜色、端口与 NodeResizer 使用官方节点和连接生命周期。                           |
| 避障路由 | 把节点矩形与方向引脚同步到 libavoid Router，增量维护连接并执行事务；中间折点写入 edge data，生成正交 SVG path。几何比较忽略路由结果字段，防止结果写回形成循环。 |
| 可编辑边 | 根据直线、Catmull–Rom、正交算法生成路径及控制点。拖动、键盘、插入和删除修改控制点；正交段按方向约束联动端点，连接草稿可用空格采样途经点。                       |
| 辅助线   | 建立节点边缘与中心锚线索引，按可见性、线类型和距离选择候选。把位置或缩放 change 吸附后提交给官方 `applyNodeChanges`，Canvas 按 viewport 和 DPR 绘制指示线。     |
| 剪贴板   | 保存选中的节点与内部连线；粘贴生成新 ID、重映射边端点并平移位置。复制、剪切、粘贴按钮和键盘操作使用同一状态逻辑。                                               |
| 历史     | past/future 两个快照栈保存节点、边数组。在编辑入口保存操作前快照，新操作清空 future，撤销和重做在两栈之间转移当前图。                                           |
| 多选分组 | 计算所选节点的外接边界，创建组节点并转换组内相对坐标；移动或改变子节点后调整组范围。解组把组内位置转换回画布绝对位置。                                          |
| 父子关系 | 拖动结束查找相交父容器，建立 parentId 并扣除父节点位置；位置限制在容器范围内。脱离时还原绝对坐标，排序保证父节点先于子节点。                                    |
| 自由绘制 | 采样 client 坐标和压力，预览用缩放补偿笔宽；提交时转成 flow 坐标，求包围盒并保存节点局部点。perfect-freehand 生成轮廓，缩放时从原始点重算。                     |
| 本地协作 | Yjs Maps 保存图、光标和连接草稿；投影缓存保留本地选择和尺寸。自有 BroadcastChannel 传输同步状态和增量，输入框、复选框、节点、边和远端光标通过同一文档更新。     |

源码位置和建议阅读顺序见 [源码指南](./readable-source.md)。共享官方 React Flow、依赖外部化、CSS 和 WASM 部署方式见 [架构](./architecture.md)。
